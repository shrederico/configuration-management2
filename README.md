# Конфигурационное управление

Практическая работа №1, вариант №10: эмулятор командной оболочки на Python.

Проект находится в [pract1](pract1/README.md). В этой папке расположены
`src/`, `tests/`, скрипт запуска, примеры и подробные инструкции.

```sh
cd pract1
python3 scripts/create_vfs.py
sh run.sh --vfs examples/deep.zip
```

Полная демонстрация: `sh demo.sh` из папки `pract1`.
Тесты: `python3 -m unittest discover -s tests -v` из папки `pract1`.

Учебные ZIP создаются локально генератором и не включаются в репозиторий
согласно правилу Г1 методических указаний.
