# Практическая работа №1. Эмулятор командной оболочки

**Дисциплина:** Конфигурационное управление  
**Вариант:** 10  
**Язык программирования:** Python 3

## Описание проекта

Проект представляет собой эмулятор командной оболочки, разработанный
на языке Python.

Разработка выполняется поэтапно в соответствии с методическими указаниями.

На первом этапе реализован базовый интерфейс командной строки (CLI),
позволяющий пользователю вводить команды и получать результаты их обработки.

## Этап 1. Прототип командной оболочки

Реализованные возможности:

- Интерактивный ввод команд.
- Отображение приглашения командной строки (prompt).
- Получение имени пользователя и компьютера из операционной системы.
- Разбор введённой строки на команду и аргументы.
- Заглушка команды `ls`.
- Заглушка команды `cd`.
- Завершение работы командой `exit`.
- Обработка неизвестных команд.
- Обработка пустого ввода.

На данном этапе команды `ls` и `cd` являются заглушками.
Они выводят своё название и полученные аргументы, но не выполняют
операции с файловой системой.

## Требования

Для запуска необходим Python 3.

Дополнительные библиотеки не требуются.
Используются стандартные модули Python:

- `getpass` — получение имени пользователя операционной системы.

## Запуск программы

Перейти в каталог `pract1` и выполнить:

```bash
sh run.sh
```

После запуска появится приглашение командной строки:

```text
username@hostname:~$
```

## Пример работы

```text
username@hostname:~$ ls
Команда: ls
Аргументы: []

username@hostname:~$ ls documents photos
Команда: ls
Аргументы: ['documents', 'photos']

username@hostname:~$ cd documents
Команда: cd
Аргументы: ['documents']

username@hostname:~$ hello
Ошибка: неизвестная команда 'hello'

username@hostname:~$ exit
```

## Архитектура программы

Программа состоит из трёх основных функций.

### parse_command()

Принимает строку, введённую пользователем.

Разделяет её на название команды и список аргументов.

### run_command()

Принимает команду и её аргументы.

Определяет поддерживаемую команду и выполняет соответствующую заглушку.

При вводе неизвестной команды выводит сообщение об ошибке.

### main()

Основная функция программы.

Отвечает за:

- Формирование приглашения командной строки.
- Получение пользовательского ввода.
- Вызов парсера команд.
- Обработку команды `exit`.
- Передачу остальных команд на выполнение.
- Поддержание интерактивного цикла.

## Этап 2. Конфигурация

Параметры `--vfs PATH` и `--script PATH` задают путь к ZIP-VFS и
стартовому скрипту UTF-8. При запуске оба параметра выводятся на экран.
Скрипт показывает команды и результаты, продолжает работу после ошибок.
`exit` завершает сеанс; без `exit` после скрипта начинается ручной ввод.
Проверки: `sh scripts/check_config.sh` и
`sh scripts/check_config_errors.sh`.

## Этап 3. Виртуальная файловая система

`python3 scripts/create_vfs.py` создаёт три учебных ZIP в `examples`:
минимальный, с несколькими файлами и с тремя уровнями каталогов.
Архивы не включаются в коммиты (Г1 методички).
`VirtualFileSystem` читает ZIP в память; каталоги хранятся в множестве,
файлы — в словаре с данными base64. Распаковки на диск нет.
Проверки: `sh scripts/check_vfs_minimal.sh`,
`sh scripts/check_vfs_files.sh`, `sh scripts/check_vfs_deep.sh`.
